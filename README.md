# 乙6 QUEST — DAY1 プロトタイプ v0.1

危険物取扱者・乙種第6類を親子で学ぶための、ビルド不要の小さなWebアプリです。

## 動かし方

- `index.html` をPCのブラウザで開くだけで試せます。
- 公開するには、GitHubで新しい **公開** リポジトリ `otsu6-quest` を作り、`index.html` をリポジトリ直下にアップロードします。
- リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** を選び、`main` と `/(root)` を指定して保存します。
- 表示されるGitHub PagesのURLをPC・iPad・iPhoneで開けます。

## 含まれる機能

- 「お父さん」「ケイタ」の選択
- DAY1の短い解説（第6類の入口）
- 固定された5肢択一問題5問、採点と解説
- 途中回答・解答履歴のブラウザ内保存（localStorage）
- 学習ログのコピー、選択中学習者の記録削除

## 大切な制限

- **クラウド同期なし**：端末・ブラウザごとに別の記録です。
- 同じ端末ではプロフィールを切り替えられますが、**認証はありません**。どちらの記録も閲覧できます。
- ブラウザの履歴・Webサイトデータの削除等で記録が失われる場合があります。必要なら「週末用の学習ログをコピー」で控えてください。
- GitHub Pagesに公開したWebアプリは公開サイトです。個人情報・秘密情報はファイルへ追加しないでください。
- 収録した問題は独自作成であり、公式過去問の転載ではありません。法令範囲や濃度等の詳細は今後の教材で確認します。
- DAY2以降、クラウド同期、ログイン機能、親子比較画面はまだありません。

## 次の段階

DAY1を親子で試した後、出題難易度・説明量を調整し、DAY2〜DAY7と週末共通テストを追加。その後にFirebase Authentication / Firestoreによる端末間同期を検討します。
